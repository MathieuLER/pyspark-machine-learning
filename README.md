Ce projet consiste à prédire le taux de churn client d'un opérateur téléphonique. 

Le churn, ou taux d'attrition, désigne la proportion de clients qui résilient ou ne renouvellent pas un contrat générant des revenus récurrents, reflétant souvent un désalignement produit/marché ou un problème d'accompagnement client.

Le notebook python est fourni ainsi que le jeu de données et les consignes. Le notebook a été exécuté dans Google Collab
